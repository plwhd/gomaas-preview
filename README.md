# 李鹏飞个人网站

[访问网站](https://lipengfei.top/) · [文章](https://lipengfei.top/articles.html)

这里是个人网站 **lipengfei.top** 的静态发布仓库。

网站整理个人介绍、项目实践与学习记录，文章涵盖 UI 与视觉设计、摄影与艺术、穿搭与风格、阅读随笔及技术与商业。

## 仓库说明

网站使用 Eleventy 生成静态页面，由 GitHub Pages 托管。

本仓库保存部署所需的 HTML、CSS、JavaScript、图片及其他公开资源。文章草稿、内部工作文档与构建工具在独立的源码工作区维护，不包含在此发布仓库中。

## 本地预览

下载或克隆仓库后，在仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。本地预览不需要安装前端构建依赖。

## 图片与字体

图片来源、作品信息及署名见对应文章。字体许可证保存在 [assets/fonts](assets/fonts/) 中；中文采用设备系统字体。

网站内容会持续修订，最新公开版本以 [lipengfei.top](https://lipengfei.top/) 为准。
