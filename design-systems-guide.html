设计系统与 UI 组件参考

发布于 2026.10.19版本：V1AI 辅助：Codex

关键词：设计系统　·　UI 组件　·　Ant Design　·　Fluent 2　·　界面设计

This article is available in Chinese.

八项设计系统与组件资源，涵盖视觉规范、交互模式与界面实现。前两项为优先推荐。

置顶 Ant Design

蚂蚁集团与开源社区维护的企业级设计体系，涵盖设计原则、交互模式与 React 组件。中文资料便于查阅，适合后台、工作台等界面设计；可先看表单、导航与操作反馈。

置顶 Fluent 2

微软的跨平台设计系统，覆盖 Web、Windows、iOS 与 Android。可重点参考字体、色彩、动效与无障碍规范，学习一套视觉语言如何适配不同设备。

Carbon

IBM 的开源设计系统，提供基础样式、组件、交互模式与数据可视化规范。适合参考数据密集界面中的层级、表格与图表设计。

PatternFly

Red Hat 维护的开源企业级设计系统。包含筛选、批量操作、向导、列表与详情等模式，适合参考管理控制台及复杂业务流程。

Kendo UI

Progress 的商业 UI 组件套件，覆盖 React、Vue、Angular 与 jQuery。可查看数据表格、图表与排期等复杂组件示例；React 版含部分免费组件，高级组件与功能需要相应许可。许可说明

PrimeReact

PrimeTek 的 React UI 组件库，提供表格、菜单、弹窗等业务组件及主题定制能力。适合参考常见组件的细节，以及同一组件在不同主题下的呈现。

shadcn/ui

提供可直接取得、修改与扩展源码的组件，作为构建自有组件库的基础。适合希望定制视觉与交互行为的项目，也需要自行维护修改后的代码。

Arco Design · 移动端

字节跳动 Arco Design 体系下的 React 移动端组件库，面向 H5 与 App 内嵌网页。适合参考移动网页中的表单、选择器、弹层与触控交互。
