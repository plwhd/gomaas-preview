我的职业选择与大学探索

发布于 2026.10.04个人回顾AI 辅助：GPT-6.1 Sol

关键词：职业选择　·　大学经历　·　视觉传达设计　·　UI 设计　·　自我认识

This article is available in Chinese.

国庆假期，我有时间回顾此前的学习和工作经历。最近在网络上浏览到一些其他同学的个人博客，也让我有了丰富自己网站的想法，希望把一些经历和思考整理下来。

回看大学专业与就业的选择，获得较好的收入是当时一个直接的动机。它影响了我对大学专业、设计岗位和就业路径的判断，也使我把不少精力投入到课程学习、作品集和寻找实习中。

这次整理的最终目的，是为接下来的工作作准备。当时依据什么作出选择，后来做了哪些尝试，实际结果与最初设想有什么差别，都可以帮助我更清楚地认识自己，并判断现在应当把精力投入哪里。

升学和职业选择最初的考虑

最初学美术，一个重要原因是希望考上一所较好的大学。在河南相对激烈的升学竞争中，一次老师的讲座给了我启发，让我认为美术是一条更有可能实现这一目标的路径。我经历过两次高考，第一次高考后的志愿填报可能存在一些问题；第二年，我的文化成绩达到了一个比较满意的分数，在填报志愿时有了更多选择，最终进入了武汉科技大学。

进入大学后，我心里有一个目标：去腾讯这样的企业工作。这个目标主要来自我在网络上接触到的信息。进入大厂能够获得较高的薪资，是我当时希望走这条路径的直接原因。

与此同时，我认为自己的英语成绩不理想，也不太容易提高，因此对考研或保研没有太高的期待。我更关注如何通过学习一项具体技能，获得进入企业工作的机会。

这一考虑影响了我大二时选择视觉传达设计专业。按照当时从网络上获得的认识，我认为腾讯等企业的视觉设计岗位相对更关注作品，对学历的要求没有那么突出。因此，我开始围绕视觉设计师这一目标，学习字体设计、海报设计等网络课程。

从视觉设计转向 UI 设计

最初，我希望通过视觉设计进入腾讯，但个人尝试之后，没有形成自己预期的成果。后来，我通过网络课程和博主的介绍，开始了解 UI 设计。

通过那位博主的介绍，我了解到 UI 设计也是进入大厂、获得较高薪资的一种方式。按照当时获得的认识，我认为与程序员、运营等岗位相比，UI 设计受到的学历限制相对较小，是一条比较直接的就业路径。了解之后，我购买了一门课程，学习相关知识。

这次方向调整仍然与收入和就业机会有关。我先有了进入大厂的目标，再根据自己了解到的岗位信息选择学习内容。从视觉设计到 UI 设计，具体路径发生了变化，最初的动机则比较一致。

大学期间，我也尝试过包装、C4D、三维建模、字体设计等方面的学习。到了大三，我把大部分精力放在了整理作品集和寻找实习上，希望将已经学到的内容用于实际求职。

从作品集到七牛云的实习

整理完作品集后，正好赶上大三暑假，我开始投递简历、寻找实习。很幸运，我进入了七牛云，在 @清清 的团队中工作，她是我的领导。我在这段工作中学到了很多。

在 UI 设计岗位上，我参与了云控制台、AI 平台和边缘计算相关产品工作，接触了需求讨论、方案协作与产品交付。此前对工作的认识主要来自网络，进入团队后，我开始有了实际参与产品工作的经历。

清清在团队中给予过我指导。在我离职、毕业之后，她也联系过我，邀请我考虑是否有兴趣回到公司工作。我对此很感激，这也是这段工作经历中希望保留下来的记忆。

大学里的其他探索与生活

大学期间，我经常去图书馆，也学习过摄影等艺术类通用课程。除了职业准备，我还参加过学校的摄影媒体部门，拍摄过一些学院活动。

我也跑步，大学期间累计跑了八百多公里。现在回看，我认为自己的身体素质还算不错，过去的运动经历仍然对现在有影响。

毕业后的一段相识

大学期间，我没有发展一段感情的想法。毕业后，出于发展一段感情的考虑，我认识了一位女生，我们也见过面。现阶段，我们都以维持生活为先，暂时没有精力考虑感情方面的事情。

让回顾服务于接下来的行动

我曾提出一个安排：在毕业后的两年内广泛探索、尝试，暂时不把挣钱放在首位。这一想法与现阶段维持生活、寻找工作的需要同时存在。具体如何安排，需要落实到实际行动中。

目前，我的职业方向是云计算、云服务销售及相关商务拓展岗位。此前在七牛云接触云产品的经历，以及个人产品中的服务调研、选型和验证，为这一方向提供了实践基础。

从视觉设计到 UI 设计，再到实习和工作，我曾依据网络信息选择学习方向，也通过作品集和实际岗位获得了进一步的认识。梳理这些经历，可以帮助我更具体地说明自己作过哪些选择、实际参与过什么，以及当前方向有哪些已有基础。

这次回顾最终要落实到接下来的工作。先把已经发生的经历和实际参与的内容说明清楚，为求职交流准备具体材料；再通过学习、求职和工作实践检验当前方向，根据结果调整投入。个人网站可以保留这些记录，既方便自己回看，也让读者了解我的经历与选择。
