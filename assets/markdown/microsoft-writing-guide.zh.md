微软《写作风格指南》包含语气、用词、语法和内容组织等不同章节。本文选取其中与日常中文写作较相关的六项建议。

英文引句为原文短句，中文为摘意；中文示例由本文另拟。

## 一、先把重点告诉读者

> Get to the point fast

**摘意：尽快进入重点。**

把读者最关心的信息放在前面，让人容易找到需要作出的选择或下一步行动。通知先说发生了什么变化，解释先回答眼前的问题，再补充背景。[原文：十大写作建议](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice)

写之前，可以先问自己：读者看完第一段，应该知道什么？如果关键信息还藏在后面，开头就需要调整。

## 二、用自然、容易理解的语言

> Write like you speak.

**摘意：像与人交谈一样表达，并把文字读出声来。**

避免不必要的术语和复杂句子。写完后读一遍，往往能发现拗口、拖沓或不自然的地方。[原文：十大写作建议](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice)

语气也要适应读者所处的情境。遇到问题时，读者需要的是明确、有帮助的回应；涉及严肃事情时，应当认真、体谅。友好并不意味着处处轻松，而是在合适的时候提供有用的信息。[原文：微软品牌语气](https://learn.microsoft.com/en-us/style-guide/brand-voice-above-all-simple-human)

## 三、删除多余文字

> Prune every excess word.

**摘意：删去每一个多余的词。**

保留足以帮助读者理解和判断的信息，删去重复的铺垫和没有增加信息的修饰。[原文：十大写作建议](https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice)

中文写作中，“在这个过程中”“从某种意义上来说”“需要进行相关操作”等表达，有时可以直接删掉或换成具体说法。

但精简也需要判断。必要的条件、依据和操作步骤应当保留，否则文字虽然变短，读者却更难理解。

## 四、用准确的动词说明动作

> Keep it active whenever you can.

**摘意：条件允许时，优先使用主动表达。**

尽量说明谁在做什么，让行动和责任容易辨认。被动表达也有用途，例如强调受到影响的对象，或避免在错误提示中指责用户，应当根据语境选择。[原文：动词](https://learn.microsoft.com/en-us/style-guide/grammar/verbs)

在中文里，可以先检查动作是否被冗长的说法掩盖：

- “对文档内容进行修改” → “修改文档内容”
- “后续将开展相关核对工作” → “接下来核对数据”

不必机械地让每句话都以动词开头。关键是让读者看清：谁来做、做什么、涉及什么对象。

## 五、同一个意思，尽量使用同一个词

> If you mean the same thing, use the same word.

**摘意：表达同一个意思，就使用同一个词。**

用词一致，可以减少读者判断“这几个词是否指同一件事”的负担。[原文：用词](https://learn.microsoft.com/en-us/style-guide/word-choice/)

例如，“下载”“导出”“保存”可能代表不同操作。如果确实不同，就应说明区别；如果说的是同一个操作，就尽量固定名称。

说明文字中，必要的重复有助于读者对应信息。为了避免重复而不断更换说法，反而可能造成歧义。

## 六、让读者浏览时也能找到信息

**摘意：用清楚的标题、较短的段落和适当的列表组织内容。**

读者常常先浏览，再决定仔细阅读哪里。重要信息需要容易被发现，较长的内容也需要清楚的结构，帮助读者定位。[原文：便于浏览的内容](https://learn.microsoft.com/en-us/style-guide/scannable-content/)

可以根据内容选择组织方式：

- 标题说明这一节具体讲什么。
- 一个段落围绕一个主要意思展开。
- 有先后顺序的操作使用编号。
- 并列项目使用列表。
- 需要逐项比较的内容使用表格。

结构应当帮助阅读。内容很短时，也不必为了形式再拆出许多小标题。

## 一个中文改写示例

下面是一则假设的会议通知，用来综合说明这些方法。

修改前：

> 为方便各位同事提前安排相关工作，现将原定于本周三下午召开的项目沟通会议调整至本周四下午三点，会议地点保持不变，请各位知悉并按时参加。

修改后：

> 项目沟通会由本周三下午改至本周四15:00，地点不变。请按时参加。

修改后的通知保留了会议名称、原时间、新时间、地点情况和参加要求，删去了不影响行动的铺垫。读者能够较快找到真正需要记住的信息。
