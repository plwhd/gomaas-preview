# 关于负情绪

作者：李鹏飞  
发布于：2026-10-16

负情绪就是我们常说的“负面情绪”，指那些让我们感到不舒服、想回避，或者消耗心理能量的情绪体验。这里沿用日常表达，用它来统称一类情绪。

**常见的负情绪有哪些？**

- **焦虑／紧张**：对未来的不确定感到不安。
- **愤怒／烦躁**：觉得被冒犯、被阻碍。
- **悲伤／失落**：面对失去或不顺时的难过。
- **恐惧／害怕**：感知到威胁或危险。
- **内疚／羞耻**：觉得自己做错了或不够好。
- **孤独／无助**：感觉不被理解或无力改变。

**负情绪一定是“坏的”吗？**

不是。情绪本身不需要用好坏来评判，不同情绪可以发挥不同的作用：

- **恐惧**可以提醒你远离危险。
- **愤怒**可以提醒你划清边界、争取权益。
- **悲伤**可以让你停下来，寻求支持。
- **焦虑**可以提醒你重视某件事，提前准备。

负情绪可以像身体的“疼痛信号”：感受不好受，却提醒我们关注自己的处境和需要。但有了这些感受，不意味着我们对事情的判断一定准确，也不意味着可以任由情绪支配行为。

**有些情绪，是在与他人的相处中慢慢积累的。**

我们可能受到他人负情绪的影响，自己也在潜移默化中积累烦躁、紧张或不安，甚至没有意识到。

比如，一次交流中，对方不断抱怨、指责，或者用讽刺的语气说话。交流结束后，我们可能仍然绷着，随后对另一件小事失去耐心，却没有察觉两者之间的联系。

当然，自己的情绪也可能来自疲惫、压力或其他处境。需要辨认具体发生了什么，而不是一有不舒服，就认定是别人造成的。

**当发现自己有负情绪时，不要把它转移到他人身上。**

因某个人或某件事生气，却向无关的人发火、讽刺或挑剔，就是在转移情绪。别人并没有造成这件事，却替它承受了后果。

可以表达自己的难受，也可以寻求支持，比如说：“刚才发生了一件让我很烦的事，我想和你聊聊。”但倾诉不等于迁怒，不能因为自己心情不好，就要求别人忍受伤人的言语和态度。

让负情绪回到它的来源，是回到具体问题上处理：有什么矛盾需要说清，有什么行为不能接受，有什么事情可以改变。不是把怒气还给对方，更不是继续传给下一个人。

**面对他人不合理的情绪输出，要直接表明，及时抽离。**

他人有负情绪、需要倾诉，并不一定是不合理的。需要分辨的是：对方是在表达自己的感受，还是在指责、羞辱、迁怒，或者强迫你持续承接他的情绪。

发现不合理的对待，可以直接表明：

“你可以表达不满，但我不接受这样的指责。”

“这件事可以讨论，但请不要用讽刺或羞辱的方式和我说话。”

如果对方仍然继续，就暂停对话或离开。及时抽离，不必等到自己已经被卷入争吵、也开始用伤人的话回应。

自己有情绪时，不让无关的人承担；他人迁怒时，明确边界，及时退出。这样既保护自己，也减少情绪继续伤害他人的机会。

**先顾好自己，不过度关注他人。**

留意自己是否疲惫、紧张，是否需要休息，是否有事情需要处理。与其一直盯着别人的情绪、态度和反应，不如先把注意力放回自己，照顾好自己的生活和状态。

可以关心他人，但不必替每个人解决情绪，也不必把别人的每一次不高兴都当成自己的责任。把自己的状态照顾妥当，再决定愿意投入多少精力与人相处。
